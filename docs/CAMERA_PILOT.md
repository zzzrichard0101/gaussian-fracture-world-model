# 같은 장치의 손상 준비와 카메라 pilot

이 단계는 연구계획 1주차의 실행이다. 현재 완료한 것은 **같은 장치 모형에서 이어지는 순방향 수치 검증과 영상 측정 도구**다. 실제 시편·카메라, 새로운 상태 추정법, 위험 보장과 논문 기여는 아직 검증하지 않았다.

## 1. 구동부와 접합면은 다른 측정값이다

```text
움직이는 구동부 U ── 탄성 연결부 ── 이동부/접합면 X ── 고정 지지부
      입력 마커                      출력 마커 L/R
```

물체의 접합면 벌어짐을 직접 입력으로 지정하지 않는다. 구동부 변위 U를 입력하고, 출력 X는 물리 계산 또는 카메라에서 얻는다. 실제 장치가 이 역할을 수행하는지는 따로 확인한다.

기존 예시는 접합면을 별도 장치로 준비한 뒤 탄성 하중을 적용했다. 새 구현은 깨끗한 상태에서 **같은 구동부만** 사용해 준비·제하·관측·추가 하중·미래 하중을 진행한다. 목표 손상에 도달하도록 숨은 상태를 덮어쓰지 않는다.

## 2. 수치 실행

```powershell
.\scripts\run-wsl.ps1 compliant-pilot
```

설정은 `config/compliant-pilot.json`, 물리 계산은 `wmfracture/compliant_fixture.py`다. 같은 모델의 두 시간 간격 4e-5/2e-5초를 사용한다. 각 하중은 1초 증가·0.25초 유지·1초 감소·0.5초 휴식이다. 모든 단계에서 벌어짐·속도·최대 벌어짐·일·감쇠 소산·시계가 이어진다.

| 순서 | 구동부 입력 | 검사 |
| --- | --- | --- |
| 준비 | 목표 이력에 대응하는 명목 구동량으로 하중/제하 | 실제 최대 벌어짐과 목표의 차이를 기록 |
| 약한 관측 | 1.00mm까지 하중/제하 | 처음 두 상태의 응답 유사성 |
| 추가 관측 | 1.65mm 또는 수동 대조군 0mm | 같은 직전 상태에서 분기, 손상 증가 비교 |
| 미래 하중 | 각 분기 상태에서 3.50mm | 분기별 실제 이력을 이어 결과 계산 |

예제는 보정하지 않은 합성 물성이다. 준비 목표를 만드는 데 재료 값을 사용하지만 추정 알고리즘이나 물성 식별 실험은 아니다.

### 이번 실행에서 확인한 것

| 재료/이력 예제 | 실제 준비 최대 벌어짐 | 약한 관측 벌어짐 | 추가 하중의 벌어짐 | 수동 대비 추가 D | 미래 분리 |
| --- | ---: | ---: | ---: | ---: | --- |
| A | 0.880466mm | 0.555557mm | 0.985368mm | 0.012549 | 발생 |
| B | 1.025747mm | 0.555557mm | 0.916670mm | 0.000000 | 미발생 |

추가 하중의 차이는 약 **0.068698mm**다. 약한 관측의 차이는 약 4.43e-7mm였다. 두 시간 간격의 추가 관측 벌어짐 차이는 최대 약 1.1e-12m였고 분리 사건도 같았다. 이는 같은 구성식의 수치 일치이며 실물 정확도가 아니다.

두 예제는 재료와 이력이 함께 다르다. 그 분리 차이를 이력만의 인과 효과라고 해석하지 않는다. 같은 재료의 별도 대조군에서는 이력이 부분 하중의 벌어짐 궤적에 영향을 줬지만, 안정적인 단일 접합면의 단조 완전 분리 벌어짐을 이력에 따라 달라지게 만들지는 않았다.

### 실패한 준비도 남긴다

탄성 연결부가 부드러운 Ks=1000N/m 조건에서는 목표 1/2mm 이력에 대응하는 명목 명령을 줘도 실제 최대 벌어짐은 약 0.086/0.071mm였고 손상은 0이었다. 이전의 별도 준비 상태를 이 장치에서도 만들 수 있다고 가정하면 잘못된 비교가 된다.

Ks=10000N/m에서는 같은 방식으로 목표 준비에 도달했다. 따라서 실물에서는 **준비 입력값만 보고 손상이 생겼다고 간주하지 않고 실제 출력과 후속 반응을 확인**해야 한다.

결과는 `artifacts/compliant-pilot/report.json`, `sequence-summary.md`, `sequence-comparison.png`다. 원본 실행은 보고서의 `run_directory`에 있다. 기존 공개 실험의 원본 결과는 바꾸지 않았다.

## 3. 카메라 오차를 먼저 측정한다

첫 촬영은 시편 파괴가 아니라 **같은 강체판의 두 마커를 고정 촬영한 10~20초 정지 영상**이다. 시편 촬영과 비슷한 거리·조명·초점·화각을 사용한다. 마커는 명확한 모서리나 대비가 높은 작은 패턴으로 둔다.

1. 첫 프레임과 해상도를 확인한다.
2. 두 마커의 픽셀 좌표를 정한다.
3. 같은 평면의 기준 길이로 mm/pixel을 산정한다.
4. 정지 영상에서 마커 간 거리의 표준편차·드리프트·추적 실패율을 측정한다.
5. 기준 길이·원근·렌즈 왜곡·마커 위치의 바이어스를 별도로 점검한다.

아래 경로와 좌표·척도는 **실제 영상 값으로 바꾼다**.

```powershell
# 첫 프레임 확인용. 출력된 first-frame.png에서 좌표를 정한다.
.\scripts\run-wsl.ps1 python scripts/camera_repeatability.py --video /mnt/c/path/static.mp4 --extract-frame

# LEFT_X LEFT_Y RIGHT_X RIGHT_Y 및 mm/pixel을 실제 값으로 지정
.\scripts\run-wsl.ps1 python scripts/camera_repeatability.py --video /mnt/c/path/static.mp4 --points 300 400 800 400 --mm-per-pixel 0.05 --signal-mm 0.068698
```

기본 축은 영상 x축이며 `--axis DX DY`로 바꿀 수 있다. 표시는 접합면에 가까운 강체 부분에 두어 변형하는 표시 자체를 접합면 벌어짐으로 착각하지 않는다. scale은 수평 투영 거리의 척도이며 영상 평면 밖 움직임까지 자동으로 보정하지 않는다.

도구는 첫 프레임 기준 양방향 LK 추적으로 누적 drift를 줄이고 실패 프레임을 보고한다. 오차가 큰 프레임을 임의로 지워 작은 분산을 만들지 않는다. 움직이지 않는 두 마커의 거리 반복정밀도를 측정할 뿐, 절대 정확도와 동적 추적 정확도는 별도다. 영상 FPS 메타데이터를 일정한 것으로 가정하므로 가변 FPS의 시간 보정 도구가 아니다.

바이어스의 독립적인 상한이 없으면 `separation_gate_status`는 `incomplete_without_independent_bias_and_scale_assessment`다. 실제 근거 없이 `--bias-bound-mm 0`을 넣어 통과시키지 않는다. 합성 영상으로 decoder→tracker→report 실행은 확인했지만 그 정밀도를 실물 카메라 결과로 사용하지 않는다.

## 4. 0.069mm를 보려면 얼마나 정밀해야 하나

해상도 W, 촬영한 실제 가로 길이 F, 각 마커의 독립적인 픽셀 오차 표준편차 s라면 단일 거리 측정의 오차는 `sqrt(2)*s*F/W`다. 독립적인 두 관측을 비교하는 3-sigma 조건에는 `6*s*F/W`가 필요하다. 각 관측의 바이어스가 최대 b라면 차이의 여유에 `2*b`를 더한다. 시간 프레임 수로 무조건 sqrt(N)만큼 나누지 않는다.

가로 1920px, 마커 오차 0.25px, 바이어스 0이라는 **가정**에서는 다음과 같다.

| 실제 촬영 가로 길이 | 필요한 차이 | 0.068698mm 차이 |
| --- | ---: | --- |
| 50mm | 0.0391mm | 가정 안에서 구분 가능 |
| 100mm | 0.0781mm | 부족 |
| 200mm | 0.1563mm | 부족 |

50mm 화각에서도 각 관측에 0.02mm 바이어스를 허용하면 필요한 차이는 약 0.0791mm로 늘어 부족해진다. 이 표는 기기 성능을 측정한 결과가 아니다. 해상도만 높다는 이유로 실제 과제가 통과했다고 할 수 없다.

## 5. 실물 준비와 후속 과제의 진행 조건

첫 시편 묶음은 0/작은/큰 사전 하중 세 조건의 소규모 pilot으로 둔다. 재료/제작 묶음 차이를 기록하고 같은 시편을 되돌려 다른 미래를 관측했다고 가정하지 않는다.

각 촬영에는 구동부 입력 마커, 출력 마커, 기준 길이, 전체 하중/제하 및 휴식을 포함한다. 첫 과제에서는 최종 분리와 부분 하중의 변위 궤적을 구분한다. 촬영 FPS가 충분하지 않으면 빠른 균열의 정확한 발생 시각을 주장하지 않는다.

다음 네 조건이 확인되기 전에는 1주차 전체를 완료했다고 하지 않는다.

1. 같은 실물 장치에서 서로 다른 유효 이력을 준비할 수 있다.
2. 비슷한 현재 외형에서 후속 과제의 결과가 이력에 따라 달라진다.
3. 그 차이를 실제 촬영 오차와 시편 변동보다 크게 측정할 수 있다.
4. 추가 관측이 가한 실제 변화와 수동 대조군을 구분한다.

절대 Gc·힘·내부 D를 카메라로 측정했다고 해석하지 않는다. 현재 모형의 무차원 D 제한은 합성 값이며 실물 안전 지표가 아니다.

## 6. 검증과 남은 작업

현재 로컬 전체 테스트 **99개**, 별도 월드모델 환경의 관련 테스트 **44개**가 통과했다. 새 물리 테스트는 탄성 평형·일/소산 균형, 같은 장치의 준비 실패, 정확한 상태 복제/재개, 손상 비가역성과 시계 유지, 불안정 dt 거부를 검사한다. 카메라 테스트는 공통 미세 움직임, 실제 상대 subpixel 변화, 추적 실패·바이어스 취급을 검사한다.

이번 결과는 전진 과제 가능성이다. 아직 새 likelihood·SMC·구간 상한·정책·Gaussian 영상 기반 추정을 구현한 것이 아니다. 다음 계산 단계는 이 모형에서 관측 데이터와 특권 상태를 분리하고, 강한 추론/위험 기준선을 동일 예산으로 비교하는 것이다. 실제 카메라 gate는 실측 영상과 척도 점검 이후에만 판단한다.
