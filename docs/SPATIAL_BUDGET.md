# 전체 물리 계산 예산을 맞춘 제안분포 비교

**사전에 고정한 혼합 제안은 저렴한 물성 혼합보다 나아지지 않았다.** 같은 물리 계산 예산에서 두 잡음 모두 평균 정답 오차가 조금 컸고, 수렴 검사는 혼합 제안 0/8, 단순 물성 혼합 1/8이었다. 반응 기반 제안의 낮은 잡음 ESS 증가는 유지됐지만, 이번 두 예산·독립 난수 조건에서 수렴 통과로 이어지지 않았다.

이전 [반응 기반 제안 실험](SPATIAL_TRANSPORT.md)의 후속이다. 최종 노드 수만 맞추던 비교에서 나아가, pilot·중심 정합·유한차분·준비 이력 재생·미래 분기를 포함한 물리 계산 예산을 맞췄다. 기존 **네 상태×두 잡음의 8개 개발 이력**을 그대로 사용한다. 새 시편·보류 검증·폐루프 관측 실험은 아니다.

## 파이프라인과 기준선

```mermaid
flowchart LR
    A[같은 공개 입력과 관측] --> B[방법별 새 물리 bank]
    B --> C[pilot과 제안 적응 비용 차감]
    C --> D[남은 예산으로 최종 물성 평가 수 결정]
    D --> E[범위 안 물성점의 준비와 실제 이력 재생]
    E --> F[모든 미래 입력 분기 계산]
    F --> G[같은 관측 우도와 전체 제안 밀도 보정]
    G --> H[두 예산과 독립 적응 반복 비교]
```

| 방법 | 제안 | 물리 계산이 필요한 준비 |
| --- | --- | --- |
| `prior_qmc` | 원래 균일 물성 prior | 없음 |
| `physical_mixture` | 20% 균일 + 80% 초기 물성 Gaussian | pilot 512점만 계산 |
| `response_chart` | 20% 균일 + 80% 정합된 반응 Gaussian | pilot + 중심 정합과 유한차분 |
| `hybrid_equal` | 20% 균일 + 40% 정합된 물성 Gaussian + 40% 반응 Gaussian | 바로 위와 같은 적응 |

주 비교는 혼합 제안과 **pilot만 쓰는 저렴한 물성 제안**이다. 혼합 제안과 반응 제안은 같은 정합 중심·같은 적응 비용을 사용하므로 넓은 Gaussian을 추가한 효과도 따로 볼 수 있다. 물성 기준선은 앞선 구현의 초기 물성 제안과 수치적으로 같으면서, 사용하지 않는 중심 정합을 계산하지 않도록 했다.

[설정](../config/spatial-budget.json)은 본 실행 전에 고정했다. 앞선 제안 설정은 그대로 사용하고 혼합 비율도 한 가지로 고정했다. 결과를 본 뒤 폭·비율·seed를 조정하지 않았다. 참 물성과 평가용 정답은 예측 JSON 저장·SHA256 고정 뒤에 읽는다.

## 예산을 어떻게 셌나

단위는 **단일 물성점의 한 증분 평형 계산**이다. 벡터화된 Python 함수 호출 수나 CPU 시간과 다르다. 같은 고정 64증분 법칙에서 비영 입력의 하중·제하는 물성점마다 128회다. 준비 입력·실제로 실행한 관측 입력·모든 미래 분기의 비용을 포함한다. 0 입력의 기존 계산 경로는 평형 계산을 호출하지 않으므로 0회다.

두 예산은 이력·방법·독립 반복마다 **1,572,864회와 3,145,728회**다. 방법 간·이력 간 물리 캐시를 공유하지 않는다. 난수점과 공개 관측은 공통으로 사용하지만 물리 응답은 방법마다 다시 계산한다.

```text
setup = pilot + 중심 정합 + 유한차분의 실제 증분 계산 수
unit_cost = 물성점 하나의 준비 + 전체 관측 이력 + 전체 미래 분기
K = floor((budget - setup) / unit_cost)
used = setup + K * unit_cost
```

최대 예산에서 기록한 실제 계산 수와 위 회계를 모든 실행에서 대조한다. 남는 예산은 물성점 한 개 비용보다 작다. 작은 예산 결과는 같은 제안과 샘플 흐름의 앞부분을 사용하되, **각 예산 시나리오에 setup 전체를 각각 청구**한다. 작은 예산용 cold 실행 시간을 별도로 측정한 것은 아니다. 최대 예산 실행 시간만 fresh bank 생성·pilot·적응·밀도 계산·물리 계산·요약까지 측정한다. 같은 Python 프로세스에서 방법 순서를 반복별로 회전했으며, 엄밀한 실행 시간 통계 실험은 아니다.

## 범위 밖 Gaussian 추출을 처리하는 방법

이전과 동일하게 전체 Gaussian 혼합 밀도 q를 사용한다. 물성 범위 밖 추출은 물리 계산을 하지 않고 가중치 0으로 남긴다. 범위 안 물성 평가 수가 K개에 도달하면 추출을 끝낸다. 종료 조건에는 관측 우도·미래 결과·정답을 사용하지 않는다.

이때 범위 안 추출의 분포는 전체 혼합 q를 입방체에 조건화한 것이다. 그 정규화 상수는 모든 가중치에 공통이라 **자기정규화 posterior 평균·사건 확률에서 상쇄**된다. 이 실행에서 가중치의 평균을 주변우도 추정으로 사용하지 않는다. 성분별로 경계에서 잘라 다시 뽑거나, 좌표를 경계로 clip하는 방식과 다르다. 두 예산은 동일한 추출 흐름의 앞부분이며 범위 밖 추출도 총 추출 수에 기록한다.

## 결과

총 64개 최대 예산 실행에서 두 예산의 중첩 추정 **128행**을 저장했다. 정답 평가 전에 예측 파일을 고정했다. 전체 개발 실행은 이 머신에서 약 347초였다. 독립 시편 64개를 실험한 것이 아니다.

아래는 최대 예산 3,145,728회에서 첫 반복의 주 추정값이다. 각 잡음은 같은 네 물리 이력이며, 이 예산에서는 모든 방법이 4/4개의 추정값을 냈다. ESS는 그 네 값의 중앙값이다. **수렴 통과 수는 두 반복과 두 예산의 네 결과 전체를 비교한 것**이며 최대 예산의 ESS만 통과하면 되는 검사가 아니다. 시간은 최대 예산의 네 이력×두 반복 실행 중앙값이다.

| nominal sigma (mm) | 방법 | 중앙 ESS | 미래 gap RMSE (mm) | 수렴 통과 / 4 | 측정 시간 중앙값 (초) |
| ---: | --- | ---: | ---: | ---: | ---: |
| 0.001 | prior QMC | 1.53 | 0.06848 | 0 | 6.70 |
| 0.001 | pilot 물성 혼합 | 19.01 | 0.13034 | 0 | 6.25 |
| 0.001 | 반응 제안 | 528.30 | 0.13015 | 0 | 5.40 |
| 0.001 | 물성+반응 혼합 | 283.24 | 0.13333 | 0 | 5.36 |
| 0.020 | prior QMC | 58.63 | 0.09274 | 0 | 5.01 |
| 0.020 | pilot 물성 혼합 | 119.43 | 0.08353 | **1** | 4.82 |
| 0.020 | 반응 제안 | 39.50 | 0.08868 | 0 | 4.86 |
| 0.020 | 물성+반응 혼합 | 74.32 | 0.08891 | 0 | 4.85 |

주 비교의 혼합 제안은 단순 물성 혼합보다 개별 정답 MSE가 작은 이력이 **각 잡음에서 1/4개**였다. 낮은 잡음의 prior QMC는 정답 RMSE가 작아 보이지만 ESS가 거의 1~2이고 수렴 검사도 실패했다. 이를 posterior를 더 정확히 계산했다는 결과로 해석하지 않는다. 높은 잡음에서도 대부분 불안정하므로 작은 RMSE 차이의 일반 성능 우위를 주장하지 않는다.

![두 예산의 ESS와 정답 오차](media/spatial-budget-comparison.png)

작은 예산 1,572,864회에서 낮은 잡음 prior QMC는 첫 반복 2/4개만 추정 가능했다. 나머지 방법·잡음은 첫 반복 4/4개였다. 따라서 그림의 해당 RMSE 점은 큰 예산이나 다른 방법과 평가 이력 구성이 다르다. 두 점 사이의 오차 감소를 공정한 개선량으로 계산하지 않는다. [두 예산 전체 요약](results/spatial-budget-analysis-summary.json)에 가용성과 수치를 함께 기록했다.

앞선 실험에서 통과했던 낮은 잡음 두 상태도 **이번 독립 seed와 총 예산 조건에서는 통과하지 않았다.** 관측은 같지만 노드 수·seed·범위 조건화가 바뀌었으므로 동일 설정의 재현 시험이라고 부르지 않는다. 앞선 2/4는 그 실험의 결과로 보존하고, 안정성이 넓은 조건에서 확립됐다고 일반화하지 않는다. threshold를 결과에 맞춰 완화하지 않았다.

이번 수치만으로 실패 원인을 하나로 단정할 수는 없다. 곡면에 비해 지나치게 국소적인 Gaussian, 일부 모드의 질량 부족, 관측으로 남는 불확실성, 분리 사건 경계의 적분 오차가 서로 다르다. 현재는 검증된 연속 posterior 참조값이 없어 그 영향을 분리하지 못했다.

### 최종 샘플만 맞췄을 때 감춰졌던 비용

| 방법 | setup 계산 수: 낮은 / 높은 잡음 | 최대 예산의 최종 물성 평가 수: 낮은 / 높은 잡음 |
| --- | ---: | ---: |
| prior QMC | 0 / 0 | 4,915 / 3,510 |
| pilot 물성 혼합 | 131,072 / 262,144 | 4,710 / 3,218 |
| 반응 제안 | 622,592 / 1,097,728 | 3,942 / 2,285 |
| 물성+반응 혼합 | 622,592 / 1,097,728 | 3,942 / 2,285 |

반응·혼합 제안의 setup은 최대 예산의 약 **19.8% / 34.9%**, 작은 예산의 **39.6% / 69.8%**를 소모했다. 실제 비용은 모든 128개 예산 행에서 cap 이내였고, 최대 잔액 비율은 **0.049% 미만**이었다. 비용 단위의 반올림으로 방법별 소모가 조금 다르지만 잔액은 항상 완전한 물성 평가 한 개보다 작았다.

낮은 잡음의 반응·혼합 방식은 측정 시간이 조금 작았지만, 이는 새 bank를 쓰는 이 머신·배치 크기의 관측값이다. 같은 증분 계산 수라도 벡터화·메모리·선형대수 비용에 따라 시간이 달라진다. 수렴·정확도가 확보되지 않아 이를 유효한 추정 정확도당 속도 개선으로 채택하지 않는다.

## 이번 결과로 바꾸는 연구 판단

이번 **고정 50:50 Gaussian 혼합은 주기여 후보로 채택하지 않는다.** 모든 혼합 방식이 불가능하다는 결론은 아니지만, 같은 8개 이력에서 비율과 폭을 계속 바꾸며 성공 조건을 고르는 것은 피한다. 원래 prior를 유지하는 밀도 보정·재현 가능한 예산 회계는 기반 코드로 남긴다.

다음은 먼저 개별 미래 평균과 분리 사건의 차이를 만드는 가중치·모드·물성 구간을 분해하고, 독립 참조 적분 또는 SMC 같은 강한 기준선으로 계산 오차와 남는 물리 불확실성을 구분하는 것이다. 평균 gap이 안정돼도 사건 경계가 불안정한 사례를 따로 다뤄야 한다. 그 근거를 얻은 뒤 공간 손상 이력·모드 경계의 구조를 이용하는 표현의 기여를 판단한다. 이번 비교에는 SMC를 포함하지 않았다.

새 준비 이력의 보류 평가와 탐침 정책 연결, 전체 가능 영역 위험 상한, Gaussian 영상 연결은 여전히 남아 있다. 점 추정 오차나 ESS만으로 다음 단계의 안전한 실행을 허용하지 않는다.

## 범위와 재현

같은 알려진 안정 준정적 법칙·세 구역 접합면·E와 좌우 준비 입력의 균일 prior·두 위치 수치 관측을 사용한다. 경험적 수렴 검사는 두 독립 pilot/본 샘플 반복과 두 예산을 모두 비교한다. 최소 ESS 40, 미래 gap 평균 최대 차이 0.005mm, 사건 확률 최대 차이 0.02의 기존 임계값을 유지한다. 두 반복의 일치는 검증된 posterior 오차 상한이 아니다.

이번 비교로 일반 3D 파괴·학습 World Model·Gaussian 영상·실물 성능·위험 상한이나 novelty를 주장하지 않는다. 기존 구간 위험 판정은 이 추정값으로 대체하지 않는다.

```powershell
.\scripts\run-wsl.ps1 python scripts/spatial_budget_evaluate.py
.\scripts\run-wsl.ps1 python scripts/report_spatial_budget.py
.\scripts\run-wsl.ps1 test -q tests/test_spatial_budget.py
.\scripts\run-wsl.ps1 python scripts/publish_results.py
.\scripts\run-wsl.ps1 python scripts/validate_public_docs.py
```

기존 WSL NumPy·SciPy·Matplotlib의 CPU 경로를 사용한다. 새 설치·GPU·Houdini·Unreal·실제 촬영은 필요하지 않다. 예산과 실제 준비·관측·미래의 계산 수 일치, setup 차감, 혼합 밀도, 범위 조건화 후 원래 prior 복구, 중첩 예산 추출, 기존 물성 기준선과의 일치에 신규 테스트 6개를 추가했다. 전체 **270개** 테스트를 통과했다.
