# 반응 기반 제안분포: 일부 얇은 관측 영역의 수치 안정화

**새 샘플링 경로를 구현했고, 낮은 잡음의 네 개발 이력 중 두 개가 수렴 검사를 통과했다. 높은 잡음 네 이력은 모두 실패했다.** 예측 오차·전체 비용·위험 판정의 우위를 입증한 결과는 아니다.

이전 [연속 prior 실험](SPATIAL_CONTINUOUS.md)은 32개 이력 모두에서 수렴 검사를 통과하지 못했다. 이번에는 그중 이미 본 네 물리 상태의 두 잡음 조건, 편향 하나·잡음 반복 하나만 선택했다. 총 **8개 개발 이력**이며 새로운 보류 시편이나 새 폐루프 실행이 아니다. 앞선 32개 결과와 성공률을 직접 비교하지 않는다.

## 무엇을 바꿨나

```mermaid
flowchart LR
    A[실행 입력과 두 위치 관측] --> B[균일 물성 prior의 pilot 512점]
    B --> C[32개 재료 축 anchor와 반응 정합]
    C --> D[국소 반응 Jacobian으로 Gaussian 방향과 폭 설정]
    D --> E[20% 균일 + 80% Gaussian 혼합 제안]
    E --> F[각 물성에서 준비와 실제 입력 이력 재계산]
    F --> G[기존 관측 우도 / 전체 제안 밀도]
    G --> H[가중 미래 벌어짐과 분리 확률]
    H --> I[독립 적응 반복과 노드 수의 수렴 검사]
```

원래 물성 공간에서 균일하게 뽑는 방식은 관측에 맞는 얇은 영역을 놓치기 쉽다. 반응이 빠르게 달라지는 방향은 좁게, 잘 구분되지 않는 방향은 넓게 뽑도록 국소 선형 근사를 사용했다. 초기 두 프레임으로 정합을 시작하고 이후 실제 관측 이력 전체로 중심과 방향을 계산한다. 새 물성점의 손상 이력을 이전 점에서 복사하지 않고, 같은 장치의 준비 단계부터 다시 계산한다.

이는 **국소 반응을 이용하는 중요도 샘플링 제안분포**다. 반응 좌표의 전역 역함수나 새 학습 모델을 만든 것은 아니다. 유한차분 Jacobian은 샘플을 배치하는 휴리스틱이며 검증된 민감도 상한이 아니다.

## 원래 prior를 어떻게 유지하나

물성은 E와 좌·우 사전 준비 입력 세 개다. 앞선 실험과 같은 E 1.3~2.8J/m², 준비 입력 각각 0.8~1.8mm의 직육면체 균일 prior를 유지한다. 단위 입방체의 물성 좌표를 u라 하면 제안은 다음과 같다.

```text
q(u) = 0.2 * 1_cube(u) + 0.8/32 * sum_k Normal(u; center_k, covariance_k)
weight(u) ∝ 1_cube(u) * original_bounded_likelihood(u) / q(u)
```

- 각 Gaussian의 밀도에는 Cholesky 행렬식과 **모든 겹친 성분**이 들어간다. 선택된 성분 하나의 밀도만 쓰지 않는다.
- Gaussian은 전체 실수 공간에 정의한다. 범위 밖 추출은 버려서 다시 뽑지 않고 가중치 0으로 남기며, 전체 노드 수에 포함한다. 잘린 Gaussian의 정규화 상수를 생략하는 오류를 피한다.
- 물성 범위의 일정한 부피 인자는 prior와 제안에서 상쇄된다. 전역 비선형 반응 좌표로 변환한 적이 없으므로 별도의 반응 Jacobian 행렬식을 곱하지 않는다.
- 적응 단계의 완화한 Gaussian 우도는 제안 설계에만 쓴다. 최종 가중치는 기존 **유계 관측 오차와 채널별 지속 편향**의 우도다.
- 균일 성분이 탄성 plateau·다른 역상에도 양의 제안 밀도를 남긴다. 이는 점근적인 지지집합 보존이며, 유한 샘플에서 모든 모드를 찾았다는 보장은 아니다.

평탄 우도 대조 실험에서 보정 후 균일 prior의 평균과 별도 영역의 질량을 회복했다. 이는 밀도 구현 검사이며 실제 posterior의 수렴 증거를 대체하지 않는다.

## 고정한 비교 조건

[설정](../config/spatial-transport.json)을 본 실행 전에 저장했다. 기존 입력·관측은 바꾸지 않았다. 각 반복에 독립적인 pilot seed와 최종 Sobol scramble을 사용했다. pilot 512점, 중심 32개, 최종 노드는 512·1,024·2,048개다.

| 방법 | 중심 | Gaussian 공분산 | 최종 밀도 보정 |
| --- | --- | --- | --- |
| `prior_qmc` | 없음 | 없음 | 균일 prior 직접 적분 |
| `physical_mixture` | 초기 반응과 재료 축으로 선택 | pilot 물성 공분산 | 전체 혼합 밀도 |
| `projected_physical` | 전체 관측으로 정합 | 같은 pilot 물성 공분산 | 전체 혼합 밀도 |
| `response_chart` | 바로 위와 동일 | 국소 반응 Jacobian의 방향·폭 | 전체 혼합 밀도 |

주 비교는 **같은 정합 중심을 쓰는 마지막 두 방법**이다. 결과를 보고 좋은 seed를 선택하지 않고 첫 반복의 2,048노드 결과를 주 추정값으로 사용한다. 참 물성과 정답 미래는 예측 파일 저장·SHA256 고정 이후 평가 단계에서만 읽는다. 기존 평가 메타데이터는 개발 이력 선택에 사용했으므로 독립 보류 검증이라고 부르지 않는다.

수렴 검사는 두 독립 반복 각각의 1,024·2,048노드 결과 네 개를 모두 비교한다. 전부 추정 가능하고, 최소 ESS 40 이상이며, 미래 gap 평균의 최대 차이 0.005mm 이하, 분리 확률 최대 차이 0.02 이하여야 통과한다. 이는 경험적 검사이며 정확한 posterior 오차 경계가 아니다.

## 결과

각 행은 같은 잡음의 네 물리 이력이다. ESS는 첫 반복·2,048노드의 중앙값이며 추정 불가 시 0도 포함한다. RMSE는 **추정 가능한 이력에서만** 계산한다. 특히 낮은 잡음의 prior 기준선은 2/4개만 포함하므로 나머지 행과 정확도를 공정하게 비교할 수 없다.

## 비용과 남은 실패

적응 한 번마다 물성점 평가 **1,920회**가 추가됐다. 이는 단일 점 평가 횟수이며 벡터화된 함수 호출 수가 아니다. 각 평가가 준비·관측 이력을 계산하므로 실제 파라미터별 증분 평형 계산은 **491,520~835,584회**였다. 여기에 반복별 공유 pilot 512점과 균일 prior bank 2,048점의 계산이 있다.

| 제안 | 최종 단계 새 물성 평가 / 이력·반복 | 범위 밖 추출 / 2,048 |
| --- | ---: | ---: |
| 물성 혼합 | 1,107~1,510 | 128~531 |
| 정합 후 물성 혼합 | 855~1,465 | 173~783 |
| 반응 기반 혼합 | 872~1,589 | 49~766 |

균일 성분 약 410점은 공유 bank에서 재사용했다. prior 기준선의 로그에 새 평가 0회가 기록되는 것은 이미 계산한 bank를 썼기 때문이며 계산 비용이 없다는 뜻이 아니다. 반응 기반 최종 단계의 추가 파라미터별 증분 평형 계산은 599,040~1,081,472회다. 전체 네 방법·두 반복·8이력 개발 실행은 이 머신에서 약 223초였으며 단일 방법의 반복 측정 시간은 아니다. **같은 최종 노드 수 비교는 같은 전체 계산 예산 비교가 아니다.**

국소 차트 총 512개 중 rank 2와 rank 3이 각각 256개였다. rank 부족 방향을 삭제하지 않고 폭 상한 0.04의 정규 Gaussian으로 유지했다. 이 상한·곡률·중심 간 빈틈이 어떤 실패를 만들었는지는 후속 진단이 필요하다. 현재 두 독립 반복만으로 전역 적분 정확도를 인증하지 않는다.

이번 단계는 posterior 적분 경로만 바꿨다. **기존 구간 위험 판정·보류 결과는 그대로이며, 넓은 영역의 구간 부풀림을 해결하지 않았다.** 새로운 탐침 정책·Gaussian 영상·학습 World Model·실물 데이터도 추가하지 않았다. 표준 중요도 샘플링을 조합한 것만으로 논문 novelty를 주장하지 않는다.

## 다음 판단 순서

후속 [전체 물리 계산 예산 비교](SPATIAL_BUDGET.md)에 1번과 2번의 QMC·단순 물성 혼합·반응 및 혼합 제안 비교를 구현했다. SMC와의 비교는 포함하지 않았다. 아래 항목은 이 실험 이전에 정한 판단 순서이며 후속 결과는 별도 문서에 보존한다.

1. 같은 중심에서 물성 공분산과 반응 공분산을 함께 쓰는 넓은 제안 기준선을 고정하고, 높은 잡음 실패가 제안 폭에 얼마나 민감한지 비교한다. 새 설정은 별도 후속 결과로 남긴다.
2. pilot·적응·준비 재생·미래 계산을 모두 포함한 같은 예산의 prior QMC·간단한 혼합·SMC와 비교한다. ESS 증가만으로 효율을 판단하지 않는다.
3. posterior가 안정된 개발 사례에서 정답 오차와 관측 잔차·미래 다양성을 분리한다. 새 준비 이력의 보류 평가와 폐루프 탐침 연결은 그 뒤에 한다.
4. 허용 판정에는 별도의 전체 가능 영역 상한이 필요하다. 샘플 posterior의 최대 위험이나 사건 확률로 기존 구간 판정을 교체하지 않는다.
